# 杨仙瑶个人网站 · 全面升级版

双击 `index.html` 即可本地预览。网站为静态站点，可部署至 GitHub Pages、Cloudflare Pages、Vercel 或任意静态托管平台。

## 本次升级

- 重构为“定位—精选项目—个人优势—经历与荣誉—联系”的单页叙事
- 提炼三个代表性案例，减少简历式信息堆叠
- 全新响应式视觉系统，兼顾桌面与手机访问
- 支持中英文切换、移动端菜单、滚动动效和减少动效偏好
- 保留旧的 `research.html` 与 `internship.html` 地址并跳转至新版对应内容
- 整合 Moonbot Tutor、古蜀覆面、腾讯灵芽和创作者增长等新简历内容
- 内置两份岗位定向 PDF 简历入口
- 新增个人爱好视觉占位区，后续可直接替换真实素材
- 重构为“分类项目库 → 经历时间线”的展示逻辑
- 新增统一案例详情页；每个项目只维护一份数据，可同时进入多个分类
- 二苏诗词情感识别同时归入 AI 产品与数字人文，两个入口指向同一案例页

## 主要文件

- `index.html`：内容与页面结构
- `styles.css`：完整视觉与响应式设计
- `script.js`：中英文、菜单与动效
